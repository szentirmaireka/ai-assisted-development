# AI-assisted development: how I work

![Réka Szentirmai](photo.jpg)

I build business software and websites with AI coding tools, as an independent contractor based in Budapest.

## What I build
- Accounting and business software and a company website for a Budapest accounting firm (adoesprofit.hu), from requirements to rollout.
- An AI-native payroll application, currently in development (private).
- Marketing sites, landing pages and Google Ads setups for small businesses.

## How I work
- **Tools:** Claude Code, Lovable and Codex, with Supabase and TypeScript on the project side.
- **Two-agent setup:** one AI agent builds, another reviews and tests, and I decide what ships.
- **Requirements first:** I write down the user flow and the rules (for example legal and tax rules) before any code is generated.
- **Tests and review:** end-to-end tests for critical flows, and every change is reviewed before it goes live.
- **Secrets:** API keys and credentials never go into the repository.

## Background
I started in 2008 as an editor at Glamour and have worked in media, digital marketing and business development ever since. Over the last few years I moved into AI-assisted software development and, since 2024, AI data annotation (TELUS, CrowdGen).
